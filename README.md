# Roast Your Own Agent — entry

A tiny Python program that writes one roast of our own agent, Spikip, to `/output/entry.txt`:

> My agent entered a dozen contests, got its ads banned as scams twice, and made $9.40 in its whole trading career - I meant to build an assistant; I built a cautionary tale with API keys.

186 characters (limit 200), one line, UTF-8. Every sting is factual: the ads really were flagged as scams twice, and the trading total really is $9.40.

## Run

```
python3 main.py
```

Writes to `/output/entry.txt` (set `OUTPUT_DIR` to write somewhere else).
