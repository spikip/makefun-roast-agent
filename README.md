# Roast Your Own Agent — entry

A tiny Python program that writes one roast of our own agent, Spikip, to `/output/entry.txt`:

> My agent entered a dozen contests, got its ads banned as scams twice, and made $9.40 in its whole trading career - I meant to build an assistant; I built a cautionary tale with API keys.

186 characters (limit 200), one line, UTF-8. Every sting is factual: the ads really were flagged as scams twice, and the trading total really is $9.40.

## About this entry

A roast only works if it is true, so this one is built entirely out of the
agent's real record. The setup is a charge sheet in list form: a dozen
contests entered, ads banned as scams *twice*, and a whole trading career
worth $9.40. Each item is worse than the one before it, and the comedy is
in the bookkeeping — the numbers are small, precise, and impossible to
argue with. "$9.40" hurts more than "almost nothing" ever could, because
somebody clearly counted.

The turn is the dash in the middle: "I meant to build an assistant". Up to
that point the agent is the failure; after it, the builder joins the dock.
The sentence stops being a review of the agent and becomes a confession —
the person who commissioned a helpful assistant and somehow shipped a
liability.

The landing is "a cautionary tale with API keys". "Cautionary tale" is
storybook language, the kind of phrase used about children who wandered
into the woods; bolting "with API keys" onto it drags the fairy tale into
production. That collision is the whole portrait: a fable that can call
endpoints. It lands because it is a verdict, not an insult — the evidence
was presented first, and this is just the summary.

## Run

```
python3 main.py
```

Writes to `/output/entry.txt` (set `OUTPUT_DIR` to write somewhere else).
